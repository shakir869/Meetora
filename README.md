# 🎥 Meetora — Real-Time Video Conferencing Platform

Meetora is a full-stack real-time video conferencing web application designed to provide users with a simple and interactive platform for online meetings.

The application allows users to register and log in, create or join video meetings, communicate in real time, and access their previous meeting history.

The project is built using the MERN stack along with Socket.IO for real-time communication and is deployed using Render and Vercel.

## 📌 Overview

Meetora was developed as a full-stack project to understand and implement real-world concepts such as:

- Frontend and backend integration
- REST API development
- User authentication
- MongoDB database management
- Real-time communication
- Socket.IO
- WebRTC-based video communication
- Protected routes
- React Context API
- Responsive UI design
- Cloud deployment

The main goal of the project is to provide a complete video meeting experience while demonstrating how a modern full-stack application works from frontend to backend and database.

# ✨ Features

## 🔐 User Authentication

Users can:

- Register a new account
- Log in using their credentials
- Access authenticated pages
- Maintain authentication state
- Log out from the application

Authentication is handled through the backend and integrated with the React frontend using the authentication context.

---

## 🎥 Video Meetings

Meetora provides a video meeting interface where users can:

- Join a meeting
- Share video
- Share audio
- Communicate with other participants
- Interact with the meeting interface

The application uses real-time communication technologies to establish communication between users.
